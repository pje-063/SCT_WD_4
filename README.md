# SCT_WD_4

## PlanPulse - Task & Schedule Studio

## SkillCraft Technology - Web Development Internship

This project is an interactive and responsive full-screen Task & Schedule Studio developed using HTML, CSS, and JavaScript.

## Features

Full-Screen Bento Grid Split-Layout
Real-Time Progress Bar Tracking
Dynamic Category Tagging (Work, Personal, Study, Health)
Live Keyword Search & Task Status Filtering (All, Pending, Done)
Light & Dark Theme Toggle with High Readability
Interactive Confetti Particle Celebration Effect
Persistent Data Storage via LocalStorage
Fully Responsive Layout for All Device Sizes
Clean & Modular Code Structure

## Technologies Used

HTML5
CSS3
JavaScript (Vanilla)
